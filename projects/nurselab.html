// PROFESSIONAL PROJECT · GOLDVR · MEDICAL TRAINING

NurseLab.

A VR training app developed at GoldVR with the medical school of the University of Ferrara. Students learn how to approach a patient, use medical instruments and answer quizzes written by their own professors, all defined in JSON and created through an online authoring tool.

// 02 — THE CHALLENGE

Let professors build the training, and keep it running smoothly in VR.

The university needed to create and update training scenarios by itself, without asking a developer to rebuild the app each time. At the same time, the application had to hold a stable frame rate on a standalone headset, where frame drops quickly make a VR experience uncomfortable.

01 / TRAINING

Direct interaction with the patient

Students approach a patient, use medical instruments and take part in the scenario as they would in practice.

02 / AUTHORING

Scenarios created by the client

Patient states, behavior cycles, quizzes and events come from JSON files. An online tool generates them, so professors create experiences on their own.

03 / PERFORMANCE

Frame drops on standalone VR

The app showed several frame-rate drops, which had to be tracked down and fixed on Quest 3 / 3S.

// 04 — HOW IT WORKS

From the online tool to the headset.

The app is a runtime that interprets data. The content lives outside of it, which is what makes new experiences possible without a new build.

STEP 01

Author online

The client creates an experience in the online tool. When finished, the tool generates all the JSON files.

STEP 02

Deliver via server

Experiences are downloaded from a server onto the headsets, and only for specific users, selected through JSON.

STEP 03

Train in VR

The JSON defines the patient's initial state, the behavior cycle of the experience, the quizzes and the events.

// 06 — TECHNICAL REFLECTION

What this project demonstrates.

NurseLab goes beyond the Unity scene: it covers a data-driven runtime, a web tool for non-technical users, server-side content delivery and performance work on standalone hardware. It is a complete pipeline from authoring to headset, built so that the client can keep creating content independently.
