// 02 — THE CHALLENGE

Reconstructing 3D models at runtime from files and MRI.

The core engineering challenge was making the application dynamically reconstruct 3D anatomical models at runtime directly from user-selected files or raw MRI data. Instead of relying on pre-baked assets, the system had to generate accurate models on demand, ensuring seamless inspection for clinicians across desktop and VR.

// 03 — WORKFLOW PIPELINE

From file selection to interactive 3D inspection.

The system processes user input directly inside the application, transforming raw medical data into fully manipulable 3D structures ready for surgical planning.

STEP 01

Select a model

The user chooses the anatomical target to explore directly from the application interface.

STEP 02

Rebuild at runtime

The 3D model is generated in real time from the selected file or underlying MRI data.

STEP 03

Inspect and adapt

Scale the model, modify materials, and adjust individual organ transparency.
