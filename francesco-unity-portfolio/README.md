# Francesco Baiano — Unity Developer Portfolio

A responsive static portfolio concept built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. For a more reliable local preview, run a static server from this directory, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included
- `index.html`: single-page portfolio with project filtering, skills, experience and contact.
- `projects/monasterio.html`: sample case study page.
- `style.css`: dark theme, cyan accent, responsive layouts and reduced-motion support.
- `script.js`: mobile menu, category filters and subtle reveal effects.
- `assets/design-reference.png`: generated visual direction reference, if supplied.

## Before publishing — important checklist
1. Replace all placeholder / CSS concept visuals with real screenshots or approved project media.
2. Verify every project description, role, date, platform and technology.
3. Replace generic GitHub, LinkedIn and ArtStation URLs with your real profile URLs.
4. Confirm the email address is the one you want public.
5. Add your actual CV at `assets/Francesco-Baiano-CV.pdf`.
6. Verify permission to publish images from professional projects. Do not include patient data or confidential information.
7. Remove projects that are not ready or that you cannot publicly discuss.
8. Add a real video only if it can be shared publicly; use a poster image and avoid autoplay with sound.
9. Check external links and test mobile layouts.

## Deploy to GitHub Pages
1. Create a GitHub repository, for example `francesco-baiano-portfolio`.
2. Upload the contents of this folder (not just the ZIP).
3. In repository Settings → Pages, choose deploy from the `main` branch and root folder.
4. Save and wait for GitHub Pages to publish the static site.

No build step is required.
